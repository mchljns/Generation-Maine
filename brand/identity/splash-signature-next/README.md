# Signature Next — splash page concept

This is a separate review version of Signature. The existing `brand/identity/splash/` page and its generator are untouched.

## Design decisions

- Keep Signature's spruce, white, marigold, Bricolage Grotesque, DM Sans, and existing logo assets.
- Use the existing Maine line mark as the hero visual. The page is designed to carry without photography or video.
- Replace the nine screen-length placeholder creator sequence with three concise story themes. The first season's people and towns are still to be confirmed, so the page says what is planned without inventing testimonials or published stories.
- Shorten the path from the hero to the concept, story themes, and approach. The page uses flat fields, restrained motion, and obvious links.
- Remove a simulated newsletter success state and dead social links. The follow section says when those channels will open.
- Use local fonts and vector artwork, semantic headings, a skip link, visible focus states, and reduced-motion support.

## Before launch

1. Replace or expand the story themes with approved creator stories, names, towns, and real story links. The page works without adding footage.
2. Add real social and newsletter URLs. Change the follow section to working links and a live signup only after those destinations are ready.
3. Confirm legal, privacy, and funder-disclosure copy with the project owner. The present Signature page omits the Maine Policy Institute line following a documented client request, though earlier strategy documents recommended disclosure.

Open `index.html` directly or serve this folder as a static site. No build step is required.
